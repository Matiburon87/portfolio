# Matías Asaro - Portfolio

Modern, responsive IT portfolio designed for recruiters. Built with HTML5, Tailwind CSS, and vanilla JavaScript.

## ✨ Features
- **Editorial Tech Aesthetic**: Terminal-inspired design with JetBrains Mono typography.
- **Bilingual Support (i18n)**: Instant Spanish/English toggle without page reload.
- **Deep Dark Mode**: Optimized accessibility and high contrast for developers.
- **Interactive Slideshow**: Project showcases with manual navigation and hover-to-visit overlays.
- **Performance Optimized**: Vanilla JS logic, ultra-fast loading with Tailwind JIT via CDN.

## 🛠 Tech Stack
- **Styling**: Tailwind CSS (CDN JIT mode)
- **Fonts**: JetBrains Mono, DM Sans
- **Icons**: Custom SVG
- **Logic**: Vanilla ES6 JS (custom i18n system, carousel, theme engine)
